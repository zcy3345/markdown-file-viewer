# Markdown File Viewer

**只能看，不能改。** 双击一个 `.md` 文件，砰地一下打开 —— 和 Edge 打开 PDF 的体验一样。

## 它是什么

一个专门用来「看 Markdown」的小工具。**一个 exe 文件**，打开就是一篇排版好的文档：
没有编辑器、没有工具栏、没有侧边栏、没有设置页。

## 为什么这么简单

因为这个工具**只做一件事**：把 Markdown 渲染成好看的页面给你看。

| 它没有 | 于是 |
|---|---|
| 编辑功能 | 不会改坏你的文件，也不会有「保存了吗」的焦虑 |
| 侧边栏 / 文件树 | 不用在软件里找文件 —— 你本来就在资源管理器里 |
| 设置页面 | 配色只有三档，右上角点一下；其他参数经过实测调好，不需要你调 |
| 后台进程 | 平时完全不运行。双击才被拉起，渲染完 0.15 秒就自己退出 |
| 缓存 | 每次打开重新渲染，磁盘上不留下任何东西 |

结果就是：**下载一个 exe，双击就完事。**

## 怎么用

**1. 下载** `mdv.exe`（右侧 Releases）

**2. 让它接管 .md 文件**（一次就够）：

- 右键任意 `.md` 文件 → **打开方式** → **选择其他应用** → 找到 `mdv.exe` → 勾选「始终使用」
- 或者打开终端跑一次 `mdv.exe --install`（只写当前用户注册表，不需要管理员）

**3. 完事。** 以后双击任何 `.md`，直接看到排版好的页面。

> 想撤销？右键 → 打开方式 → 换成别的程序，或者 `mdv.exe --uninstall`（会把原来的默认程序还原）。

## 打开之后

- **代码块**：220+ 种语言高亮、行号、一键复制，长行横向滚动
- **数学公式**：KaTeX 渲染，矩阵、分段函数、积分、求和都正常
- **表格 / 任务列表 / 脚注 / 本地图片**：都是 GFM 标准行为
- **三档配色**：右上角「正常 / 灰度 / 暗色」。灰度档把代码颜色换成亮度台阶 + 粗细/斜体，
  黑白阅读也分得清 token；选择会被记住
- **记住阅读位置**：同一篇文档再打开，回到上次的位置

## 有多快

| 场景 | 耗时 |
|---|---|
| 双击 → 窗口出现（Edge 已开着）| **约 0.35 秒** |
| 双击 → 窗口出现（Edge 没开）| 约 0.5–0.6 秒（Edge 自己的启动成本）|
| 渲染一份 6 个代码块 + 6 个公式的文档 | 约 30 毫秒 |
| 常驻内存 | **0**（进程渲染完就退出，峰值约 6 MB）|

## 系统要求

- Windows 10 / 11
- 一个 Chromium 系浏览器：**Edge**（系统自带）、Chrome、Brave、Vivaldi 都行

## 它不是什么

- ❌ 不是编辑器 —— 一个字都改不了
- ❌ 不是笔记软件 —— 不管理文件、不建索引
- ❌ 不是 Obsidian / Typora 的替代品 —— 那些是写作工具，这个是「看」的工具
